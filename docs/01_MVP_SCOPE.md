# MVP Scope — V2 Private Beta

## Objective

Launch a reliable Android/iOS private beta that proves users can track everyday money, save toward goals, scan receipts, and understand money across home/living currencies.

## Included

- short onboarding
- local profile
- current country + home country
- living currency + home currency
- localization-ready architecture
- accounts
- manual income
- manual expense
- transfers
- categories/subcategories
- local transaction history
- offline-first Drift/SQLite storage
- dashboard
- monthly/category budgets
- savings goals
- goal contributions
- savings milestones
- basic motivation/streak support
- multi-currency transaction model
- currency metadata/precision
- favorite FX pairs
- FX converter
- reference FX rate source + timestamp
- historical FX snapshot on converted records
- receipt scanner
- OCR confirmation before save
- basic recurring bills/income
- basic analytics
- notification controls
- privacy controls
- local data export path defined

## Optional during late private beta

- authentication
- encrypted cloud backup
- multi-device sync
- rate alerts
- CSV export

## Excluded from first private beta

- conversational AI coach
- bank aggregation
- actual money transfer/remittance
- investment trading
- credit scoring
- advanced family permissions
- full multilingual OCR coverage
- web dashboard
- wearable apps

## MVP quality bar

- no lost transactions
- deterministic calculations only
- transfers do not distort income/expense
- historical FX values remain stable
- currency precision is correct
- FX quotes show source/timestamp/staleness
- OCR never silently saves uncertain totals
- core entry/view flows work offline
- private beta targets roughly 15–25 meaningful screens
