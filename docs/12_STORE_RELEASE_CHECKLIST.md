# Store Release Checklist

## Product

- [ ] Production app name
- [ ] App icon
- [ ] Splash assets
- [ ] Screenshots
- [ ] Store description
- [ ] Support page
- [ ] Privacy policy
- [ ] Terms of service

## Android

- [ ] Package/application ID
- [ ] Signing configuration
- [ ] Release build
- [ ] Play Console setup
- [ ] Data disclosure
- [ ] Content rating
- [ ] Account deletion
- [ ] Target SDK verified against current requirements
- [ ] Production testing

## iOS

- [ ] Bundle ID
- [ ] Signing
- [ ] App Store Connect
- [ ] Privacy information
- [ ] Age rating
- [ ] Account deletion
- [ ] Production testing

## Quality

- [ ] Crash monitoring
- [ ] Analytics
- [ ] Error reporting
- [ ] Backup
- [ ] Restore
- [ ] Security review
- [ ] Privacy review
- [ ] Accessibility review
- [ ] Offline review

## Final verification

- [ ] No debug endpoints
- [ ] No development credentials
- [ ] No test notifications
- [ ] No test accounts in production
- [ ] Production AI limits configured
- [ ] Cost monitoring enabled
- [ ] Support process ready
