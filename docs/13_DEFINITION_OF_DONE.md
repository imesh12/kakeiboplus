# Definition of Done

A feature is complete only when:

- [ ] Product requirement exists
- [ ] User flow exists
- [ ] UI is implemented
- [ ] Empty state exists
- [ ] Loading state exists
- [ ] Error state exists
- [ ] Offline behavior is defined
- [ ] Backend is implemented
- [ ] Database migration exists
- [ ] Validation exists
- [ ] Security review completed
- [ ] Unit tests exist
- [ ] Integration tests exist where appropriate
- [ ] Analytics event is defined where useful
- [ ] Documentation is updated
- [ ] Manual QA completed
- [ ] No known critical issue remains
